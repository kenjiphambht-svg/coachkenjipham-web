## Verification metadata convention

**baseline_evidence_commit** records the repository commit examined before a governance layer; it is not a claim that a new file existed at that commit. **last_verified** records the already-existing commit whose repository state was actually inspected when the document's claims were last checked — it is always a real SHA, never a future placeholder. G0 files were verified against merge commit **a45e4242c0e68f52e0004ee8dd5d02745e4212dd**. G1 and G1.1 verified the merged main state at **fe0739d6d88ba8c9b9a1a6bc9b467bc0f22f5dae**. No document may defer this field to a future merge with a placeholder; a later layer that re-verifies evidence updates last_verified to the commit it actually inspected, in its own scoped change.

## Machine-instruction load chain — verified, not assumed

- The Claude Code harness automatically loads `CLAUDE.md` (which imports `AGENTS.md` via `@AGENTS.md`) and every `.claude/rules/*.md` into session context. Evidence: direct in-session observation (31/07/2026) — all five rule files appear verbatim in Claude Code session context; no markdown file references them (`grep -rn "brand-voice" --include="*.md" .` → only this registry and the file itself). Markdown cross-reference greps cannot see this mechanism; do not re-classify these rules as orphans on grep evidence alone.
- `.claude/skills/**` load on demand through the skill mechanism, not automatically.
- `.agents/skills/**` is a manually maintained, byte-for-byte mirror of `.claude/skills/**` for non-Claude agents. There is no `.agents/rules/` mirror, so `.claude/rules/**` do **not** reach Codex automatically; Codex relies on `AGENTS.md` and the Reading Bundles.
- **Mirror parity rule:** any change to a file under `.claude/skills/**` must update its `.agents/skills/**` counterpart in the same commit, and vice versa. Verify with `diff -r .agents/skills .claude/skills` (must be empty). Drift between the mirrors is a governance defect to report, not tolerate.
