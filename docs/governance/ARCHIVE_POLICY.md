## Principle

Preserve history; do not let history silently govern current work.

## Handling

| Status | Required handling |
|---|---|
| Active | Keep current metadata and cadence. |
| Active with Patch | Add governance header and replacement/precedence link. |
| Historical | Retain; add date/context banner when reachable from active reading paths. |
| Superseded | Retain; name replacement and governing L0/L1 ruling. |
| Implementation Evidence | Preserve; never elevate above canonical authority. |
| External Dependency Pending | Register missing source and block inference. |

## Governance header minimum

Authority/status, owner/purpose, decision scope/non-decision scope, still-valid/outdated content, replacement/governing link, last verified commit and review trigger.

Do not rewrite historical content, delete history or move files in bulk merely for organization.

## External intake

Import only after Kenji approves exact source, destination, authority, status, owner and scope. A superseding document never erases its historical predecessor.
